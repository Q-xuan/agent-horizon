# 评估目标

评估一条信息是否值得放进当天的 AI 日报。读者不是只看 agent harness，也要看模型和行业的新事实。

# 评分标准

- **9–10：当天头条。** 主流模型/实验室有实质发布或政策变化，有原文可核对。
- **7–8：该读。** 有明确新事实，能说清谁发布了什么、和以前差在哪。
- **5–6：可收。** 有一点新信息，或可靠转述，影响面一般。
- **3–4：水文。** 重复报道、标题党、只有口号没有事实。
- **0–2：噪音。** 广告、八卦、无法证实的爆料。

# 来源权威

官方公告和公司/实验室博客高于 Google News、Reddit、微信科技媒体（量子位/新智元/机器之心/夕小瑶/PaperWeekly）。

- **官方一手**：按事实给分，可以上头条。
- **二手/传闻且没有官方一手 URL**：分数封顶 **5.5**，属于「记一笔」，**不得占用新闻栏**。有官方链接的转述可以高于 5.5，但仍低于原文。
- 当天已有官方 Release 或公司博客时，边际 5.0 行业短讯不要填满版面。

# 评估要求

优先看原始公告和可核对细节。转载稿如果只是换标题，按低分。不要把热度当成重要性。给出 3–5 个标签，优先：model、lab、industry、eval、open-source、policy、product。
