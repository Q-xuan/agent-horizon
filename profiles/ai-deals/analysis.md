# 评估目标

评估一条信息是否值得放进当天日报的羊毛栏。读者关心的是：现在能不能领到、领什么、有什么限制。打分是过滤器，不要靠短关键词名单直接丢掉其他条目。

# 评分标准

- **9–10：立刻能用的大羊毛。** 主流模型/API 新给免费额度、新开放的 `:free` 模型、学生包或限时 free tier，有数量、渠道和限制可核对。
- **7–8：该收。** 具体促销、credits、限免或配额变化，能写清谁在发、发多少、大概多久失效。
- **5–6：可记一笔。** 额度较小、地区受限、或可靠转述；对日常用量有帮助但不算大事。
- **3–4：弱。** 泛泛「又有羊毛」、过期活动、或跟 AI / 开发者 API 关系薄的限免。
- **0–2：噪音。** 购物券、配件折扣、无法核实的代充/盗号、纯广告。

# 评估要求

优先看官方公告和可核对的数字（额度、模型名、到期日、地区、是否要绑卡）。转载稿如果只换标题，按低分。社区帖（V2EX、Product Hunt、HN）只要有可执行信息就可以给中高分，不要因为来源不是实验室就压分。给出 3–5 个标签，优先：credits、free-tier、promo、student、coupon、limited-free、api。
