# 公众号成稿写法

日报是原料。成稿按这篇写。不要把某一天的故事写死在这里。

排版采用 **Astro Nano** 极简主义设计语言（Nano-on-WeChat）：纯粹灰阶、骨骼分明、通透留白、等宽微框，不借彩色装饰。文字平淡利落，句子接得上，不装深刻。

参考：[WangZengqi-Writing-Style](https://github.com/chengjialu8888/WangZengqi-Writing-Style)

## Astro Nano 排版结构（Nano-on-WeChat）

排版由 `push_draft.py` 收成微信能留下的纯净 HTML。借自 [doocs/md](https://github.com/doocs/md) 和 [文颜 wenyan](https://github.com/caol64/wenyan) 的结构想法；不借它们的彩色 H2 胶囊、主题色，也不借 Mac 代码窗。二级标题不加通栏线，篇首只留导语下的发丝线。

1. **导语与发丝线（Lede & Hairline）**：
   - 篇首开头两三句为 17px 通透导语，紧跟一条 `1px currentColor scaleY(0.45)` 的极细发丝分割线。
2. **二级标题（Headings）**：
   - `## 1. 标题` 会被收成 `01.` 极简小标，保持 16px/600 字重，与正文自然呼吸，不加大色块底色或圆角胶囊。
3. **行内代码（Code Badge）**：
   - 专有名词、命令与版本号使用反引号 \`code\` 包裹，渲染为等宽冷感微框（`border: 1px solid currentColor`），自适应深浅色模式。
4. **引用块（Blockquote）**：
   - 使用 `> ` 渲染为 `2px solid currentColor` 细左边线，通透克制，无背景脏色。
5. **外链下划线（Footnote）**：
   - 微信会洗掉普通 `<a href="...">`。`push_draft.py` 会把 `[文字](https://...)` 收成编辑器标准标签：`<a target="_blank" href="https://..." textvalue="..." data-linktype="2">`。只收 `https://`。不要手写裸 `<a href>`，不要只丢一行裸 URL。订阅号正文链仍可能被洗掉，不要靠正文里的「原文：」当外链。

订阅号上「阅读原文」是最稳的外链。日报成稿文件名是 `YYYY-MM-DD.md` 时，脚本把 `content_source_url` 指到当天中文日报，压过 frontmatter 的 `source:` 和正文第一条 `https://`：

```
https://q-xuan.github.io/agent-horizon/YYYY/MM/DD/summary-zh.html
```

不要把日报的 `source:` 写成站点根路径 `https://q-xuan.github.io/agent-horizon/`，也不要用正文第一条新闻当「阅读原文」。

不要在正文打印「原文：」。微信个人订阅号在正文内不支持外链跳转，正文里无需保留「原文：」链接行，保持版面纯净。

非日期文件名的长文，才用 frontmatter 的 `source:`（必须是 `https://`）；没有 `source:` 时，用正文第一条 `https://`。

不要「我的疑问」「我的判断」这种空栏。

## 句子与排版规范

简单直接。一句一个事实。短句如刀，动词极简，段落内容充实硬核（交代系统背景、具体改动与数据指标）。

- 先介绍这个人是谁，再引他的话。
- 先说这个产品是干什么的，再写它改了什么。
- 产品名留英文。
- 中英文、中文与数字之间保留半角空格（盘古之白）。

## 每条四拍（Astro Nano 卡片结构）

每条内容独立成卡，标准结构如下：

1. `## 序号. 条目标题`（中英混排，概括核心事实）
2. `` `01 · CATEGORY` · `owner/repo` ``（微分类徽标与仓库路径）
3. **四拍叙事正文**（写进同一段，充实硬核，不要标「背景 / 变化 / 影响」）：
   - 1. 从前怎样（交代背景与技术瓶颈）
   - 2. 所以怎样（点出改的人、来源与核心考量）
   - 3. 这次改了什么（具体改动、数据结构、版本与性能数据）
   - 4. 停。自然煞住收尾，不要把「停」字输出到正文中。如果只是打算，就写打算。不要写「往后会碰到」。不要写「记下即可」。
4. `> **手记**：...`（1~2 句硬核技术洞察或工程影响推演，直击本质）

不要在卡片结尾打印「原文：」。当天日报的「阅读原文」由文件名日期指向中文 digest，不靠正文脚注。

## 不要写

- 不要把「停」字作为文字写在正文结尾
- 不要每条都盖「圈里都听过」
- 主语没点名，不要用「自己」
- 不要把 changelog 整段搬进来
- 不要「并进」
- 不要把 hard news 写成「是硬的」
- 不要「留下印」，写「加水印」
- **拒绝翻译腔**：不要「这就意味着」、「值得一提的是」、「在……方面」、「作为一个……」、「深入探讨」
- **拒绝公文黑话**：不要「意味着」、「标志着」、「赋能」、「闭环」、「抓手」、「重磅」、「全面升级」

## 篇

- 标题不超过 22 个字，只带一件真事，中英混排带空格
- 开头两三句，只说今天发生了什么
- 一篇 4–6 条
- 结尾煞住。不要「总之」
- 不要「我的疑问」「我的判断」这种空栏
